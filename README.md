# 📝 To-Do List Web App

This is a simple, minimal To-Do List application built using **HTML**, **CSS**, and **JavaScript**. It allows users to input tasks, save them temporarily, and view their list of saved tasks. The app uses a clean interface styled with Bootstrap and custom CSS.

## 🚀 Features

- Add tasks via input field.
- View all saved tasks in a pop-up alert.
- Simple and centered UI layout.
- Responsive and visually appealing design using Bootstrap and custom CSS.

## 📁 Project Structure

```
.
├── index.html     # Main HTML file
├── style.css      # Custom styles
└── app.js         # JavaScript logic
```

## 🔧 How It Works

1. Enter a task in the input field.
2. Click **Save** to add the task to memory.
3. Click **View Your Task** to see all saved tasks in an alert box.

> ⚠️ Note: Tasks are stored only in memory (JavaScript array) and are not persistent across page reloads.

## 📦 Setup

To run the project locally:

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/todo-list-app.git
   ```
2. Open `index.html` in your browser.
